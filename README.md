# Glosario proyecto final 

## 1. pwd
muestra en la pantalla la ruta completa y absoluta del directorio de trabajo actual donde te encuentras.
## 2. ls
lista de archivos y carpetas.
## 3. cd
cambia de directorio.
## 4. mkdir
crea una carpeta o direcorio.
## 5. touch
crea un archivo vacio o actualiza su fecha. 
## 6. cp
copia archivos o directorios. 
## 7. mv
Mueve o renombra archivos y directorios.
## 8. rm
Elimina archivos o directorios.
## 9. cat
Muestra el contenido de un archivo.
## 10. less
Permite visualizar un archivo página por página.
## 11. head
Muestra las primeras líneas de un archivo.
## 12. tail
Muestra las últimas líneas de un archivo.
## 13. clear
Limpia la pantalla de la terminal.
## 14. echo
Muestra texto o valores en la terminal.
## 15. man
Muestra el manual de un comando.
## 16. whoami
Muestra el manual de un comando.
## 17. date 
Muestra la fecha y hora actuales.
## 18. grep
Busca texto dentro de archivos o resultados.
## 19. find
Busca archivos y directorios.
## 20. sudo
Ejecuta un comando con permisos administrativos.
## 21 Compilador
Traduce el código fuente a otro lenguaje, como código máquina, para que pueda ejecutarse.
## 22 Intérprete
Lee y ejecuta instrucciones de un programa, generalmente durante su ejecución.
## 23 Depurador (Debugger)
Ayuda a encontrar y analizar errores en un programa.
## 24 IDE
Entorno que reúne herramientas para escribir, ejecutar y depurar código.
## 25 Editor de código
Permite escribir y modificar el código fuente de un programa.
## 26 Biblioteca (Library)
Conjunto de código reutilizable que facilita realizar tareas específicas.
## 27 Framework
Estructura de trabajo que ofrece componentes y reglas para desarrollar aplicaciones.
## 28 API
Conjunto de reglas que permite la comunicación entre programas o componentes.
## 29 Repositorio
Lugar donde se almacenan y organizan los archivos de un proyecto.
## 30 Control de versiones
Registra los cambios de los archivos y permite consultar versiones anteriores.
## 31 Git
Sistema de control de versiones que registra cambios y permite trabajar con ramas.
## 32 GitHub
Plataforma para alojar repositorios Git y colaborar en proyectos.
## 33 Rama (Branch)
Línea de desarrollo independiente dentro de un repositorio.
## 34 Commit
Registro de un conjunto de cambios en el historial de Git.
## 35 Merge
Operación que combina los cambios de una rama con otra.
## 36 Callback
Función que se pasa a otra función para que se ejecute posteriormente.
## 37 Programación síncrona
Ejecuta las instrucciones en secuencia; una operación suele terminar antes de iniciar la siguiente.
## 38 Programación asíncrona
Permite realizar tareas que tardan en completarse sin bloquear necesariamente el resto del programa.
## 39 JavaScript
Lenguaje de programación usado para agregar interactividad a páginas web y crear otras aplicaciones.
## 40 TypeScript
Lenguaje basado en JavaScript que añade tipos estáticos para ayudar a detectar errores.
